### 2.2 分层完整性

- 路由→controller→service→dao 全链路:10 个 controller 全部 import 对应 service(category/course/admin-knowledge/search/activity/ai-log 等);10 个 service、10 个 dao 一一对应;service 层无 req/res 依赖(grep 无命中)。

- 事务:主表+变更日志写入走 `withTransaction`(config/db.ts:58)。

### 2.3 参数化 SQL 抽查(5 处,无字符串拼接用户输入)

| 位置 | 语句 | 结论 |
|---|---|---|
| dao/knowledge.dao.ts:29-46 | `k.status = 'published'` 固定条件 + `LIKE CONCAT('%', ?, '%')` + `LIMIT ? OFFSET ?`,值全部走 params | ✓ |
| dao/knowledge.dao.ts:75 | 状态多值 `k.status IN (${占位符序列})` — 仅生成 `?` 个数,值走 params | ✓ |
| dao/ai-log.dao.ts:21-36 | buildFilters 三个条件均 `= ?` / `>= ?`,值走 params | ✓ |
| dao/teacher.dao.ts:21 | `t.name LIKE CONCAT('%', ?, '%')` | ✓ |
| dao/knowledge.dao.ts:154,158 | `UPDATE knowledge SET status=? WHERE id=?` / `DELETE FROM knowledge WHERE id=?` | ✓ |

全部 `${}` 插值仅限固定条件片段与列名常量(whereSql/COLS),用户输入一律进参数数组;ai/retriever/local-kb-retriever.ts 自行执行 SQL 但同样全参数化(`?` + LIKE CONCAT),符合 dao 约定精神。

### 2.4 中间件

- **requireAdmin 覆盖**:admin.routes.ts:29-31 以 `guarded.use(requireAdmin)` 统一挂载,仅 login(:26)在守卫前;middlewares/auth.ts:19-36 校验 Bearer + `role==='admin'`,缺失 401 / 角色不符 403,与契约 1.6 一致。
- **统一错误处理**:middlewares/error.ts:17-38 — HttpError 按业务码输出、ZodError→400、未知错误仅 `console.error('[unhandled]')` 并返回 500「系统繁忙,请稍后重试」,不泄堆栈(TC-10);notFoundHandler 404 兜底。
- **CORS 白名单**:app.ts:18-19 从 `env.CORS_ORIGIN` 逗号分隔取白名单(env.ts:19,默认 http://localhost:5173);cors.test.ts 覆盖。
- **会话时区 '+08:00'**:config/db.ts:23-25 `pool.on('connection') → SET time_zone='+08:00'`,并 `dateStrings: true`(:19)保证 DATE/DATETIME 按契约 1.4 字符串返回。

### 2.5 AI 链路(对照 03-AI组件设计)

- **retriever 四件套**:types.ts 接口与 03 §2 逐字段一致;local-kb-retriever 仅检索 published/上架内容、top-5、阈值 1、停用词、重叠 2-gram 整句加权(03 §2.1 v1.1);http-kb-retriever POST `{baseUrl}/retrieve`、5s 超时(03 §2.2);index.ts:13-31 工厂——未配置 KB_API_BASE_URL 用 Local,已配置 HTTP 优先、失败**级联回 Local** 并记警告。
- **chat-service**(ai/chat-service.ts):拒答(:79-82,isReliable=false → 固定话术 + sources=[],禁止编造);降级(:90-98,LlmError → 模板 + FALLBACK_NOTICE 首行);落库(user 消息检索前落库 :63;assistant 带 sources_json/mode/retriever/latency_ms :104-112;落库失败不阻塞响应 :113-115);**注入防线**(用户输入只作 user message :87,system prompt 仅固定约束 + 检索资料 :20-40,与 03 §3.1 v1 存档逐字一致,prompt 存档文件 docs/ai-logs/prompts/ai-chat-system-prompt-v1.md 存在)。
- **DeepSeek 适配器**(ai/llm/deepseek-adapter.ts):temperature 0.3、max_tokens 600、stream false、AbortController 超时(默认 20s)、非 2xx/空内容抛 LlmError;llm/index.ts 未配 Key 返回 NullLlmAdapter 调用即抛 → service 降级。与 03 §3.2/§4 参数表完全一致。

# 启动与使用手册

> 适用:新生校园知识库与入学事务辅助系统(西南交通大学)。数据已内置真实公开信息(采集底稿见 `docs/report/采集底稿-A/B.md`)。
> 日常使用只需记住:**开两个终端,各跑一条命令**——后端 `npm run dev`,前端 `npm run dev`,然后浏览器打开 http://localhost:5173/ 。

## 一、环境要求(只装一次)

| 软件 | 版本要求 | 检查命令 |
|---|---|---|
| Node.js | 22 或更高 | `node -v` |
| MySQL | 8.0 | `mysql --version` 或查看服务 MySQL80 是否在运行 |

## 二、首次部署(换新电脑时做一次)

按顺序执行(Windows 命令行 CMD 或 PowerShell):

```bat
:: 1. 确保 MySQL 服务在运行(需要管理员窗口)
net start MySQL80

:: 2. 初始化数据库:先建结构,再灌数据
::    ★ 必须带 --default-character-set=utf8mb4,否则中文会导入失败
cd /d D:\SSDA
mysql --default-character-set=utf8mb4 -u root -p < db\schema.sql
mysql --default-character-set=utf8mb4 -u root -p < db\seed.sql

:: 3. 配置后端连接(本仓库 backend\.env 已配置好可跳过;换电脑时:)
copy backend\.env.example backend\.env
::    编辑 backend\.env:DB_PASSWORD 改成本机 MySQL 密码;
::    JWT_SECRET 换成任意 16 位以上随机字符串;其余保持默认

:: 4. 安装前后端依赖(各一次)
cd backend  && npm install
cd ..\frontend && npm install
```

## 三、日常启动(每次使用)

开**两个**命令行窗口:

```bat
:: 窗口 1:启动后端(端口 3000),出现 "listening on http://localhost:3000" 即成功
cd /d D:\SSDA\backend
npm run dev

:: 窗口 2:启动前端(端口 5173),出现 "Local: http://localhost:5173/" 即成功
cd /d D:\SSDA\frontend
npm run dev
```

然后浏览器打开:**http://localhost:5173/**

**停止服务**:在对应窗口按 `Ctrl+C`。关闭窗口等效。

## 四、访问地址与账号

| 入口 | 地址 | 说明 |
|---|---|---|
| 学生端 | http://localhost:5173/ | 无需登录 |
| 管理端登录 | http://localhost:5173/admin/login | 账号 `admin` / 密码 `admin123`(首次登录后请在管理端修改) |
| 后端健康检查 | http://localhost:3000/api/health | 返回 `"db":"up"` 即后端与数据库正常 |

## 五、功能使用指南

### 学生端(无登录)
- **首页**:顶部搜索框全局搜索;分类导航进入各分类知识;
- **知识列表/详情**:按分类筛选+关键词搜索+分页;详情页展示正文、来源(单位+通知名)、更新时间;过期条目顶部显示过期横幅;
- **办事指南**:一卡通办理/校园网开户/学生邮箱/证明打印等,含办理地点、材料、流程、电话;
- **校园活动**:按最近一届真实日期收录(开学典礼、运动会、百团大战等);
- **地点查询**:按校区(犀浦/九里/峨眉)、建筑筛选,含楼层房间与用途说明;
- **课程教师**:课程/教师双 Tab 查询;
- **AI 助手**:右下角悬浮球或导航入口进入;问"校园一卡通丢了怎么补办""怎么转专业"等会返回**附带来源编号**的回答;知识库没有的(如闲聊)会明确提示"知识库未覆盖,请核实"——这是防编造设计,不是故障。当前未配置 DeepSeek Key 时为"降级模式"(本地检索整理),在 `backend\.env` 填入 `DEEPSEEK_API_KEY` 并重启后端即切换为模型生成。

### 管理端(/admin,需登录)
- **知识管理**:五状态 Tab(全部/草稿/待审核/已发布/已下架);新增知识(标题/分类/正文/来源必填,日期真实日历校验);流程:新增→提交审核→审核通过发布→学生端可见;可下架、删除(仅草稿)、查看修改日志;
- **分类/指南/活动/地点/课程教师管理**:增删改查;删除仍被引用的数据会被 409 拦截并提示条数;
- **过期信息工作台**:列出已过期/临期条目,支持编辑或下架;
- **AI 对话记录**:查看全部问答(含来源与模式标签),可导出 JSONL 文件(课程 AI 日志材料)。

## 六、常见问题排查

| 现象 | 原因与解决 |
|---|---|
| `npm run dev` 报"node 不是内部或外部命令" | 本机 PATH 中 nodejs 目录带了引号。临时解法:窗口里先执行 `set PATH=C:\Program Files\nodejs;%PATH%` 再 `npm run dev`;根治:系统环境变量里把该条目的引号去掉 |
| 浏览器打不开 5173 | 前端没启动:确认"窗口 2"在跑;或被占用:`netstat -ano | findstr :5173` 找到 PID,`taskkill /F /PID <PID>` 后重启 |
| 前端开了但接口报错/列表空 | 后端没启动:确认"窗口 1"在跑;或数据库没数据:重新执行第二步导入 |
| 打开 http://localhost:3000/api/health 返回 `"db":"down"` | MySQL 服务没运行:管理员窗口 `net start MySQL80`;或 `backend\.env` 中 DB_PASSWORD 与本机密码不符 |
| 导入 SQL 报 `Incorrect string value` | 导入命令漏了 `--default-character-set=utf8mb4`(见第二步) |
| 导入 SQL 报错后库里没数据 | 重新按顺序执行两条导入命令(schema 先、seed 后)即可,脚本可重复执行 |
| 重新执行 seed 会怎样 | **清空并重建全部业务数据(含 AI 对话日志)**。执行前备份:`mysqldump --default-character-set=utf8mb4 -u root -p ssda > backup-日期.sql` |
| 管理端登录返回 401 | 账号密码为 admin/admin123(seed 预置);若改过密码以改后为准;JWT_SECRET 变更后需重新登录 |

## 七、安全与注意事项

1. `backend\.env` 含数据库密码与密钥,**已加入 .gitignore,永远不要提交**;
2. 演示前建议:修改 `JWT_SECRET`、修改 admin 密码;
3. AI 对话日志存在数据库 `ai_chat_*` 表;`npm run export:ai-logs`(backend 目录)可导出 JSONL 到 `docs/ai-logs/exports/`(该目录不入 git,提交材料时单独打包);
4. 本机其他数据库(hotel_a/itcast 等)与本系统无关,项目只使用 `ssda` 库,请勿误操作。

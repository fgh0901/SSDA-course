## 三、问题与解决实录

| 问题 | 解决 |
|---|---|
| Windows 用户 PATH 中 nodejs 带引号,npm 子进程找不到 node | 命令级 PATH 前置修复,记录进技能库 |
| Git Bash curl 中文参数 GBK 乱码导致检索假空 | 接口实测统一改用 Node 层 UTF-8(fetch/Supertest) |
| 自定义角色类型后台派发被服务商风控拦截 | 改用通用类型+角色任务书,角色定义保留供客户端手动使用 |
| Element Plus 日期控件静默解析非法日期 | 前端捕获阶段拦截指令+后端真实日历校验双保险 |
| AI 检索 8 字短句误拒答、排序噪声 | 根因定位为步长 2 切分丢词边界,改重叠切分+覆盖率权重 |

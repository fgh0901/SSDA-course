# 项目周报(第 3 期)

## 一、本周完成工作

1. **知识库与数据库内容真实化(重点)**:按课程要求与用户决策,系统数据从虚构演示数据全面切换为**西南交通大学真实公开信息**——2 个数据研究员子 Agent 网络检索采集约 108 条候选(官方渠道为主),总控抽查 10 组样本(URL 逐字反查)全部通过,转写为 seed v2.0 灌库:51 条校园知识、31 个地点、4 条办事指南、6 条活动、9 门课程、5 位教师;官方核实 38 条/社区待核 13 条(is_verified 如实标注);全库零"示例数据"残留。
2. **AI 问答在真实数据上验证**:冒烟五问——一卡通补办/军训时间/转专业均命中真实条目并附可溯源来源;"闲聊"正确拒答且来源为空(防编造红线);俗称"熊猫卡"亦可检索命中。
3. **外部知识库适配器实装**:HttpKbRetriever(超时中止/报文校验)+ 检索器工厂级联(外部库优先、不可用自动回落本地、学生端不中断),附模拟外部知识库与 5 条测试——为知识库架构扩展预留接口。
4. **提交信息全面中文化与仓库归位**:按用户要求将 57 个未推送提交的历史信息重写为中文(备份分支可回滚),77 处文档内提交号引用同步更新;修正仓库关系——最终交付仓库为上游 paloma-dove/SSDA(协作者直推),自身 fork 仅作备份;第 1 批已推上游。
5. **UI 设计师第二轮全站精修**:管理端表格斑马纹/操作按钮层级/弹窗规范/悬浮提示,学生端首页 Hero 与骨架屏加载、AI 对话长回答排版、知识详情长正文排版;页脚数据来源声明更新为西南交通大学官方渠道。
6. **收尾与文档**:《启动与使用手册》(两步启动/首次部署/功能指南/排障);AI 工程资产双层目录归并;AI 使用日志补记数据建设与历史重写阶段。

## 三、问题与解决实录

| 问题 | 解决 |
|---|---|
| 首批数据研究员子 Agent 派发后挂起(零落盘) | 终止重派后正常;数据工程师再次挂起时由总控接管执行 |
